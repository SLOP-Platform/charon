## Bug fixed vs the draft
The summary message's marker/"Summary of N turns:" PREFIX tokens were not subtracted from the
summary budget. With a small `safety_margin_tokens` the packed output could exceed `context_window`.
Now `shape()` budgets `estimate_tokens(summary_prefix)` explicitly so compacted output always fits.

## Adversarial self-review
- Off-by-default: `shape` returns the SAME `messages` object (identity) for config None / enabled
  False / unknown window; verified via `is` + deepcopy-equality red-proof. Cannot mutate by default.
- Stateless: no module-level mutable state, no store; deterministic (two runs equal).
- Disclosure: strictly gated on `applied`; empty disclosure when not applied.
- Over-budget: output token count asserted <= window; last N turns are the exact same dict objects
  (no user-turn copy/mutation); original caller array unchanged.
