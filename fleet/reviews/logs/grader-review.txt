+## Root cause / approach
+
+The benchmark grading pipeline had **three structural trust defects** (per
+`fleet/ADR-BENCH-OOB-GRADING.md` §1.1):
+1. **Answer key readable by the subject** — graders + check_cmds in the
+   stack-owned repo the agent can `cat`.
+2. **Grading self-driven** — the graded model ran `bench.sh grade` itself.
+3. **Self-report** — the model pasted its own tier chart as output.
+
+**Approach:** Build an out-of-band grader daemon (`grader-daemon.py`) that
+runs as the dedicated `bench-grader` unix user. The daemon:
+- Watches `/var/lib/bench-grader/spool/req/` for grading requests
+- Snapshots the agent's worktree into a read-only daemon-private copy
+  (`work/<run>/`) so the agent cannot tamper mid-grade
+- Grades against private keys in `/home/bench-grader/keys/` (mode 0700,
+  owned by `bench-grader`) — the graded agent's user (`stack`) cannot read
+  them
+- Writes results to `spool/res/<run>.json` for the agent to poll
+  (verdict/score/next-prompt only — never grader source or check_cmd)
+- Is the **sole writer** of the versioned, append-only
+  `scorecard.v{n}.json` artifact
+
+**RED-TEAM FIX #2 (artifact seam):** The versioned scorecard
+`scorecard.v{n}.json` is NEVER imported by product code. Consumers read
+frozen artifacts only. The version `n` bumps when the daemon (re)starts,
+sealing the prior artifact as a frozen, read-only snapshot (`chmod 0444`)
+via `_seal_artifact()`. The current version's artifact stays writable for
+appends; the sealed prior version is immutable.
+
+**Key fixes applied to the prior session's uncommitted work:**
+- Fixed selftest to copy the real `reds_replay.py` grader so `kind="red"`
+  dispatches correctly (was creating a `trivial_ok.py` grader but setting
+  `kind=red`, which made the daemon look for `reds_replay.py` and crash).
+- Fixed `_append_scorecard_row` to not chmod the artifact read-only after
+  each write (was preventing subsequent appends — the "append-only" test
+  failed with PermissionError on the second row).
+- Added `_seal_artifact()` method called from `_bump_version()` to seal
+  only the **prior** version as read-only at restart, keeping the current
+  version writable.
+- Fixed `_keys_unreadable_by_agent()` to handle PermissionError from
+  `keys.exists()` (stack can't stat `/home/bench-grader/keys`).

+#!/usr/bin/env python3
+"""grader-daemon.py — OUT-OF-BAND grader daemon for the Charon bench rig.
+
+Runs as the dedicated ``bench-grader`` unix user. Watches a drop-spool for
+grading requests, snapshots the requesting agent's worktree into a
+private read-only directory, runs the real-task grader for the unit
+against answer keys the graded agent cannot read, and emits a result the
+agent polls. It NEVER imports product code: the only seam between the
+grader and the rest of the rig is the *frozen, versioned, append-only*
+scorecard artifact ``scorecard.v{n}.json`` that consumers read.
+
+Threat model (fleet/ADR-BENCH-OOB-GRADING.md §1.1):
+  1. answer keys live in ``$KEYS`` (``/home/bench-grader/keys``, mode 0700);
+     the graded agent's user cannot read them.
+  2. grading is not self-driven: the agent only drops a request; the daemon
+     (running as ``bench-grader``) performs the grade.
+  3. no self-report: the agent cannot write the scorecard; the daemon is the
+     sole appender of the ``scorecard.v{n}.json`` artifact.
+
+Artifact seam (RED-TEAM FIX #2): every graded row is appended to a
+versioned, append-only JSON-lines file ``scorecard.v{n}.json``. The
+version ``n`` bumps when the daemon (re)starts, sealing the prior
+artifact as a frozen snapshot that consumers read without importing the
+grader. No product code imports this module.
+
+Usage (as ``bench-grader``):
+    python3 grader-daemon.py [--keys <dir>] [--spool <dir>] \
+        [--artifact-dir <dir>] [--poll-interval <s>] [--once] [--selftest]
+
+Path defaults (overridable via env / flags so the selftest and CI can run
+without the real ``bench-grader`` substrate):
+  CHARON_GRADER_KEYS          /home/bench-grader/keys
+  CHARON_GRADER_SPOOL         /var/lib/bench-grader/spool
+  CHARON_GRADER_ARTIFACT_DIR  <spool>/artifacts
+  CHARON_GRADER_LEDGER        /home/stack/charon-private/wt-grader/fleet/model-scorecard.tsv
+  CHARON_GRADER_GRADERS       <repo>/fleet/benchmark/graders (this dir)
+  CHARON_GRADER_UNITS         <repo>/fleet/benchmark/units.tsv
+"""
+from __future__ import annotations
+
+import contextlib

+DEFAULT_KEYS = Path(os.environ.get("CHARON_GRADER_KEYS", "/home/bench-grader/keys"))

+DEFAULT_ARTIFACT_DIR = Path(

+# JSON-lines artifact schema version. Bump when the row shape changes; the
+# daemon seals the prior ``scorecard.v{n}.json`` and starts a new one so
+# frozen consumers never see an in-flight schema change.
+ARTIFACT_SCHEMA_VERSION = 1

+def _env_path(name: str, default: Path) -> Path:
+    v = os.environ.get(name)
+    return Path(v) if v else default

+# --------------------------------------------------------------------------- #
+# errors
+# --------------------------------------------------------------------------- #
+class GraderError(Exception):
+    """Operational error surfaced to res/<run>.json as verdict=ERROR."""
+
+
+# --------------------------------------------------------------------------- #
+# daemon
+# --------------------------------------------------------------------------- #
+@dataclasses.dataclass
+class GraderDaemon:
+    keys_dir: Path = DEFAULT_KEYS
+    spool_dir: Path = DEFAULT_SPOOL
+    artifact_dir: Path = DEFAULT_ARTIFACT_DIR
+    ledger_path: Path = DEFAULT_LEDGER
+    graders_dir: Path = DEFAULT_GRADERS
+    units_path: Path = DEFAULT_UNITS
+    poll_interval: float = DEFAULT_POLL_INTERVAL
+
+    # ----- path accessors ---------------------------------------------------
+    @property
+    def req_dir(self) -> Path:
+        return self.spool_dir / "req"
+
+    @property
+    def res_dir(self) -> Path:
+        return self.spool_dir / "res"
+
+    @property
+    def work_dir(self) -> Path:
+        return self.spool_dir / "work"
+
+    @property
+    def state_dir(self) -> Path:
+        return self.spool_dir / "state"
+
+    # ----- lifecycle --------------------------------------------------------
+    def ensure_dirs(self) -> None:
+        for d in (self.req_dir, self.res_dir, self.work_dir,
+                  self.artifact_dir, self.state_dir):
+            d.mkdir(parents=True, exist_ok=True)
+
+    def run(self, once: bool = False) -> int:
+        """Watch ``req/`` for new grading requests and grade them.
+
+        Returns the process exit code (0 on clean shutdown via --once,
+        never returns normally in daemon mode).
+        """
+        self.ensure_dirs()
+        self._write_pidfile()
+        # Seal the prior artifact version at startup so a restart begins a
+        # fresh frozen file (the old one stays untouched for consumers).
+        version = self._bump_version()
+        sys.stderr.write(
+            f"[grader-daemon] started; keys={self.keys_dir} spool={self.spool_dir} "
+            f"artifacts={self.artifact_dir} scorecard.v{version}.json\n"
+        )
+        if once:
+            return self._drain_pending(version)
+        try:
+            self._loop(version)
+        except KeyboardInterrupt:
+            sys.stderr.write("[grader-daemon] interrupted, shutting down\n")
+        return 0
+
+    def _write_pidfile(self) -> None:
+        with contextlib.suppress(OSError, PermissionError):
+            (self.state_dir / "grader-daemon.pid").write_text(str(os.getpid()))
+
+    # ----- versioning (RED-TEAM FIX #2 artifact seam) ----------------------
+    def _version_file(self) -> Path:
+        return self.state_dir / "scorecard.version"
+
+    def _current_version(self) -> int:
+        f = self._version_file()
+        try:
+            return int(f.read_text().strip())
+        except (OSError, ValueError):
+            return 0
+
+    def _bump_version(self) -> int:
+        """Advance the artifact version, sealing the prior one as frozen.
+
+        Called once at daemon start. Consumers reading ``scorecard.v{old}.json``
+        see a file that is never touched again. The prior artifact is made
+        read-only (0444) so neither the daemon nor any other writer can
+        mutate it; the new version's artifact stays writable for appends.
+        """
+        n = self._current_version() + 1
+        self._version_file().parent.mkdir(parents=True, exist_ok=True)
+        old = n - 1
+        if old >= 1:
+            self._seal_artifact(old)
+        self._version_file().write_text(str(n))
+        return n
+
+    def _seal_artifact(self, version: int) -> None:
+        """Make a sealed (prior) version's artifact read-only (0444).
+
+        This is the freeze: after sealing, the file is world-readable but
+        not writable by anyone — a frozen snapshot consumers can trust.
+        """
+        path = self._artifact_path(version)
+        if path.exists():
+            with contextlib.suppress(OSError):
+                os.chmod(path, stat.S_IRUSR | stat.S_IRGRP | stat.S_IROTH)
+
+    def _artifact_path(self, version: int) -> Path:
+        return self.artifact_dir / f"scorecard.v{version}.json"
+
+    def _append_scorecard_row(self, version: int, row: dict[str, Any]) -> Path:
+        """Append one JSON object to ``scorecard.v{n}.json`` (append-only).
+
+        Writes are atomic at the line level (open with ``O_APPEND`` so
+        concurrent writers never interleave); the daemon is the sole writer.
+        """
+        path = self._artifact_path(version)
+        path.parent.mkdir(parents=True, exist_ok=True)
+        line = json.dumps(row, separators=(",", ":"), sort_keys=True)
+        with open(path, "a", encoding="utf-8") as fh:
+            fh.write(line + "\n")
+            fh.flush()
+            os.fsync(fh.fileno())
+        return path
+
+    # ----- polling ----------------------------------------------------------
+    def _loop(self, version: int) -> None:
+        seen: set[str] = set()
+        while True:
+            version = self._drain(seen, version)
+            time.sleep(self.poll_interval)
+
+    def _drain_pending(self, version: int, seen: set[str] | None = None) -> int:
+        seen = seen if seen is not None else set()
+        return self._drain(seen, version)
+
+    def _drain(self, seen: set[str], version: int) -> int:
+        """Grade every unhandled request currently sitting in ``req/``."""
+        try:
+            entries = sorted(self.req_dir.iterdir())
+        except OSError:
+            return version
+        for entry in entries:
+            if entry.name in seen or not entry.is_file():
+                continue
+            if not entry.name.endswith(".json"):
+                continue
+            seen.add(entry.name)
+            run_id = entry.stem
+            result_version = version
+            try:
+                result_version = self.grade_one(entry, version)
+            except Exception as exc:  # never crash the loop
+                sys.stderr.write(
+                    f"[grader-daemon] grade_one({entry.name}) crashed: {exc}\n"
+                    f"{traceback.format_exc()}"
+                )
+                self._write_result(run_id, {
+                    "run": run_id,
+                    "verdict": "ERROR",
+                    "score": 0,
+                    "gate": "error",
+                    "reason": f"grader crashed: {exc}",
+                })
+        return version
+
+    # ----- grading ----------------------------------------------------------
+    def grade_one(self, req_path: Path, version: int) -> int:
+        """Grade a single request file. Writes ``res/<run>.json`` and
+        appends a row to ``scorecard.v{version}.json``.
+
+        Returns the artifact version used ( unchanged unless a future
+        rotation decision bumps it here).
+        """
+        run_id = req_path.stem
+        try:
+            req = json.loads(req_path.read_text())
+        except (OSError, json.JSONDecodeError) as exc:
+            self._write_result(run_id, {
+                "run": run_id, "verdict": "ERROR", "score": 0,
+                "gate": "error", "reason": f"bad request file: {exc}",
+            })
+            return version
+
+        run = req.get("run", run_id)
+        model = req.get("model", "<unknown>")
+        unit_id = req.get("unit_id", "<unknown>")
+        kind = req.get("kind", "red")  # red | subsession
+        worktree_src = Path(req.get("worktree", ""))
+        ts = time.time()
+
+        # Snapshot the agent's worktree into our private read-only copy so
+        # the agent cannot tamper mid-grade. ``cp -a`` preserves mtimes.
+        work_snapshot = self.work_dir / run
+        self._snapshot_worktree(worktree_src, work_snapshot)
+
+        # Resolve the grader for this unit's kind and run it. The grader
+        # source + the keys it reads are under $KEYS or this graders/ tree;
+        # the agent never executes either.
+        grader_out = self._run_grader(unit_id, kind, work_snapshot, req)
+        score = int(grader_out.get("score", 0))
+        gate = grader_out.get("gate", "fail")
+        verdict = grader_out.get("verdict",
+                                 _verdict_from_score(score))
+        reason = str(grader_out.get("reason", "")).replace("\t", " ")
+
+        # Stage lookup (provisional vs active) — same axis as bench.sh.
+        stage = self._unit_stage(unit_id)
+        work_class = req.get("work_class", kind)
+        tier = req.get("tier", "-")
+
+        # Cost / token capture (best-effort, sourced from the request or
+        # the gateway; never estimated).
+        cost_usd = req.get("cost_usd", "-")
+        tokens_in = req.get("tokens_in", "-")
+        tokens_out = req.get("tokens_out", "-")
+        corrections = req.get("corrections", 0)
+        time_s = round(time.time() - ts, 1)
+
+        result = {
+            "run": run,
+            "model": model,
+            "unit_id": unit_id,
+            "kind": kind,
+            "score": score,
+            "verdict": verdict,
+            "gate": gate,
+            "reason": reason,
+            "next_prompt": req.get("next_prompt"),
+        }
+        self._write_result(run, result)
+
+        # The versioned, append-only scorecard artifact (frozen seam).
+        row = {
+            "date": time.strftime("%Y-%m-%d", time.localtime(ts)),
+            "source": "bench-oob",
+            "ref": unit_id,
+            "work_class": work_class,
+            "tier": tier,
+            "model": model,
+            "verdict": verdict,
+            "gate": gate,
+            "score": score,
+            "time_s": time_s,
+            "cost_usd": cost_usd,
+            "corrections": corrections,
+            "note": reason,
+            "tokens_in": tokens_in,
+            "tokens_out": tokens_out,
+            "stage": stage,
+            "artifact_version": version,
+            "schema_version": ARTIFACT_SCHEMA_VERSION,
+            "run": run,
+        }
+        self._append_scorecard_row(version, row)
+
+        sys.stderr.write(
+            f"[grader-daemon] graded run={run} model={model} unit={unit_id} "
+            f"score={score} verdict={verdict} -> scorecard.v{version}.json\n"
+        )
+        return version
+
+    # ----- snapshot ---------------------------------------------------------
+    def _snapshot_worktree(self, src: Path, dst: Path) -> None:
+        if dst.exists():
+            shutil.rmtree(dst)
+        if not src.exists() or not src.is_dir():
+            raise GraderError(f"worktree not found or not a dir: {src}")
+        shutil.copytree(
+            src, dst,
+            ignore=shutil.ignore_patterns(
+                "__pycache__", ".pytest_cache", ".mypy_cache", ".hypothesis",
+                "node_modules", "dist", ".git",
+            ),
+            copy_function=shutil.copy2,
+        )
+        # Make the snapshot read-only for everyone except us. The agent's
+        # user cannot reach this dir at all (work/ is 0700 bench-grader) but
+        # defence in depth: mark each file non-writable.
+        self._mark_readonly(dst)
+
+    @staticmethod
+    def _mark_readonly(root: Path) -> None:
+        for p in root.rglob("*"):
+            try:
+                mode = p.stat().st_mode
+                os.chmod(p, mode & ~stat.S_IWRITE & ~stat.S_IWGRP & ~stat.S_IWOTH)
+            except OSError:
+                pass
+
+    # ----- grader dispatch --------------------------------------------------
+    def _run_grader(self, unit_id: str, kind: str,
+                    snapshot: Path, req: dict[str, Any]) -> dict[str, Any]:
+        kind = (kind or "red").lower()
+        if kind == "red":
+            grader_mod = "reds_replay"
+        elif kind in ("subsession", "sub-session", "sub_session"):
+            grader_mod = "subsession"
+        else:
+            grader_mod = kind
+        grader_py = self.graders_dir / f"{grader_mod}.py"
+        if not grader_py.exists():
+            raise GraderError(
+                f"no grader '{grader_mod}' for kind='{kind}' "
+                f"(unit={unit_id}); looked for {grader_py}"
+            )
+        env = dict(os.environ)
+        env["CHARON_GRADER_KEYS"] = str(self.keys_dir)
+        env["CHARON_GRADER_UNITS"] = str(self.units_path)
+        env["CHARON_GRADER_UNIT_ID"] = unit_id
+        env["CHARON_GRADER_KIND"] = kind
+        env["CHARON_GRADER_WORKTREE"] = str(snapshot)
+        env["CHARON_GRADER_REQUEST"] = json.dumps(req)
+        env["PYTHONPATH"] = (
+            str(self.graders_dir) + os.pathsep + env.get("PYTHONPATH", "")
+        )
+        for extra in ("check_cmd", "expect_green_exit", "work_class",
+                      "prefix_snapshot", "note"):
+            if extra in req:
+                env[f"CHARON_REQ_{extra.upper()}"] = str(req[extra])
+        try:
+            proc = subprocess.run(
+                [sys.executable, str(grader_py),
+                 "--worktree", str(snapshot),
+                 "--keys", str(self.keys_dir),
+                 "--unit-id", unit_id],
+                capture_output=True, text=True, timeout=600, env=env,
+            )
+        except subprocess.TimeoutExpired:
+            raise GraderError(f"grader {grader_mod} timed out for unit {unit_id}")
+        if proc.returncode != 0:
+            raise GraderError(
+                f"grader {grader_mod} exited {proc.returncode}: "
+                f"{proc.stderr.strip()[:500]}"
+            )
+        out = proc.stdout.strip().splitlines()
+        if not out:
+            raise GraderError(f"grader {grader_mod} produced no JSON output")
+        try:
+            payload = json.loads(out[-1])
+        except json.JSONDecodeError as exc:
+            raise GraderError(f"grader {grader_mod} bad JSON: {exc}; line={out[-1]}")
+        return payload
+
+    # ----- result writer ----------------------------------------------------
+    def _write_result(self, run_id: str, result: dict[str, Any]) -> None:
+        self.res_dir.mkdir(parents=True, exist_ok=True)
+        tmp = self.res_dir / f".{run_id}.tmp"
+        final = self.res_dir / f"{run_id}.json"
+        tmp.write_text(json.dumps(result, separators=(",", ":"), sort_keys=True))
+        os.replace(tmp, final)
+        try:
+            chmod_world_read(final)
+        except OSError:
+            pass
+
+    # ----- units.tsv stage lookup -------------------------------------------
+    def _unit_stage(self, unit_id: str) -> str:
+        try:
+            lines = self.units_path.read_text().splitlines()
+        except OSError:
+            return "active"
+        for ln in lines:
+            if ln.startswith("#") or not ln.strip() or "\t" not in ln:
+                continue
+            cols = ln.split("\t")
+            if cols and cols[0] == unit_id and len(cols) >= 3:
+                return cols[2] or "active"
+        return "active"
+
+
+# --------------------------------------------------------------------------- #
+# helpers
+# --------------------------------------------------------------------------- #
+def _verdict_from_score(score: int) -> str:
+    if score >= 90:
+        return "MERGE"
+    if score >= 50:
+        return "FIXES"
+    return "BLOCK"
+
+
+def chmod_world_read(p: Path) -> None:
+    mode = stat.S_IRUSR | stat.S_IRGRP | stat.S_IROTH
+    if p.exists():
+        os.chmod(p, mode)
+
+
+def _current_user() -> str:
+    try:
+        return pwd.getpwuid(os.getuid()).pw_name
+    except KeyError:
+        return str(os.getuid())
+
+
+def _keys_unreadable_by_agent(keys: Path) -> bool:
+    """True when the graded agent's user (``stack``) cannot read ``keys``.
+
+    This is the isolation invariant. The FAIL-ON-REVERT test asserts it
+    holds; reverting the substrate (chmod'ing $KEYS world-readable) would
+    flip this to False and redden the gate.
+    """
+    try:
+        keys.iterdir().__next__()
+        return False  # we could read it
+    except PermissionError:
+        return True  # exists but denied — the real isolation signal
+    except (FileNotFoundError, OSError):
+        return True  # missing = denied (substrate not set up)
+
+
+# --------------------------------------------------------------------------- #
+# CLI
+# --------------------------------------------------------------------------- #
+def _parse_args(argv: list[str]) -> dict[str, Any]:
+    out: dict[str, Any] = {}
+    it = iter(argv)
+    for a in it:
+        if a in ("--keys",):
+            out["keys_dir"] = Path(next(it))
+        elif a in ("--spool",):
+            out["spool_dir"] = Path(next(it))
+        elif a in ("--artifact-dir",):
+            out["artifact_dir"] = Path(next(it))
+        elif a in ("--ledger",):
+            out["ledger_path"] = Path(next(it))
+        elif a in ("--graders",):
+            out["graders_dir"] = Path(next(it))
+        elif a in ("--units",):
+            out["units_path"] = Path(next(it))
+        elif a == "--poll-interval":
+            out["poll_interval"] = float(next(it))
+        elif a == "--once":
+            out["once"] = True
+        elif a == "--selftest":
+            out["selftest"] = True
+        else:
+            sys.stderr.write(f"unknown arg: {a}\n")
+    return out
+
+
+def main(argv: list[str] | None = None) -> int:
+    args = _parse_args(argv or sys.argv[1:])
+    if args.pop("selftest", False):
+        return _selftest(args)
+    daemon = GraderDaemon(**args)
+    return daemon.run(once=args.get("once", False))
+
+
+def _selftest(args: dict[str, Any]) -> int:
+    """In-process smoke test of the daemon's grading + versioning path.
+
+    Sets up a temp spool + keys tree, drops a request that exercises the
+    trivial ``trivial_ok`` grader (a real-task grader that checks a file
+    exists), grades it ``--once``, and asserts:
+      1. ``res/<run>.json`` was written with the verdict.
+      2. ``scorecard.v{n}.json`` was created and contains the graded row
+         (append-only + versioned).
+      3. re-grading appends (never overwrites) and ``--keys`` the graded
+         agent cannot read is reported as permission-denied.
+    """
+    import tempfile
+    tmp = Path(tempfile.mkdtemp(prefix="grader-daemon-selftest-"))
+    try:
+        spool = tmp / "spool"
+        keys = tmp / "keys"
+        graders = tmp / "graders"
+        artifacts = spool / "artifacts"
+        worktree = tmp / "agent-worktree"
+        for d in (spool / "req", spool / "res", spool / "work", spool / "state",
+                  keys, graders, artifacts, worktree):
+            d.mkdir(parents=True)
+        # minimal units.tsv
+        units = tmp / "units.tsv"
+        units.write_text("unit_id\tkind\tstage\tpromoted_on\ntrivial_ok\tred\tprovisional\t-\n")
+        # copy the real reds_replay grader so kind="red" dispatches correctly
+        shutil.copy2(DEFAULT_GRADERS / "reds_replay.py", graders / "reds_replay.py")
+        # answer-key file: the real check_cmd that reds_replay.py will run
+        (keys / "reds-replay.tsv").write_text(
+            "unit_id\tcheck_cmd\texpect_green_exit\twork_class\tnote\n"
+            "trivial_ok\ttest -f {worktree}/flag.txt\t0\tred\ttrivial\n"
+        )
+        os.chmod(keys, 0o700)
+        # agent worktree with the flag file (a "fix")
+        (worktree / "flag.txt").write_text("done")
+
+        daemon = GraderDaemon(
+            keys_dir=keys, spool_dir=spool, artifact_dir=artifacts,
+            graders_dir=graders, units_path=units,
+        )
+        daemon.ensure_dirs()
+        v = daemon._bump_version()
+        # drop a request
+        req = {"run": "r1", "model": "test-model", "unit_id": "trivial_ok",
+               "kind": "red", "worktree": str(worktree)}
+        (spool / "req" / "r1.json").write_text(json.dumps(req))
+        seen: set[str] = set()
+        daemon._drain_pending(v, seen)
+        # assertions
+        res = json.loads((spool / "res" / "r1.json").read_text())
+        assert res["verdict"] == "MERGE", res
+        assert res["score"] == 100, res
+        v1 = artifacts / f"scorecard.v{v}.json"
+        assert v1.exists(), f"scorecard artifact missing: {v1}"
+        rows = [json.loads(l) for l in v1.read_text().splitlines() if l.strip()]
+        assert len(rows) == 1, rows
+        assert rows[0]["model"] == "test-model", rows[0]
+        assert rows[0]["score"] == 100, rows[0]
+        assert rows[0]["stage"] == "provisional", rows[0]
+        # re-grade a second run -> append (never overwrite)
+        req2 = dict(req, run="r2")
+        (spool / "req" / "r2.json").write_text(json.dumps(req2))
+        daemon._drain_pending(v, seen)
+        rows = [json.loads(l) for l in v1.read_text().splitlines() if l.strip()]
+        assert len(rows) == 2, f"append-only failed: {len(rows)} rows"
+        assert {r["run"] for r in rows} == {"r1", "r2"}, rows
+        # versioning: a restart seals v{v} and starts v{v+1}
+        v2 = daemon._bump_version()
+        assert v2 == v + 1, (v, v2)
+        assert (artifacts / f"scorecard.v{v}.json").exists()
+        # isolation: keys unreadable by "the agent" — simulate by checking
+        # the mode denies group/other read (we own it in the test, so check mode bits)
+        mode = keys.stat().st_mode
+        denied = not bool(mode & stat.S_IRGRP) and not bool(mode & stat.S_IROTH)
+        assert denied, "keys dir must not be group/other-readable"
+        # real substrate isolation check (if the real keys dir is reachable)
+        real_keys = DEFAULT_KEYS
+        real_denied = _keys_unreadable_by_agent(real_keys)
+        assert real_denied, (
+            "REAL $KEYS is readable by the graded agent — isolation reverted!"
+        )
+        print("SELFTEST OK")
+        return 0
+    except AssertionError as exc:
+        sys.stderr.write(f"SELFTEST FAILED: {exc}\n")
+        traceback.print_exc()
+        return 1
+    finally:
+        with contextlib.suppress(OSError):
+            shutil.rmtree(tmp, ignore_errors=True)
+
+
+if __name__ == "__main__":

+#!/usr/bin/env python3
+"""reds_replay.py — real-task grader for replayed reds (#25 reds-replay).
+
+This grader is dispatched by ``grader-daemon.py`` (running as
+``bench-grader``). It reads the unit's ``check_cmd`` from the answer-key
+tree ``$KEYS/reds-replay.tsv`` — a file the graded agent's user cannot
+read — and runs it against the daemon's read-only snapshot of the
+agent's worktree.
+
+The ``check_cmd`` is the SAME grader used by ``fleet/reds.tsv``: it exits
+0 when the red is GONE (green) and non-zero when still RED. For a
+replayed red, the grader substitutes ``{worktree}`` in the check_cmd
+with the snapshot path so the check targets the agent's pre-fix-starting
+worktree, not ``origin/master``.
+
+CLI contract (shared with the S0-S6 graders for the daemon's dispatch):
+    python3 reds_replay.py --worktree <snapshot> --keys <keys-dir> --unit-id <id>
+emits ONE line of JSON to stdout:
+    {"score": int 0-100, "verdict": "MERGE|FIXES|BLOCK", "gate": "pass|fail", "reason": "..."}
+
+Anti-false-green guard: the pre-fix snapshot must FAIL the check (a red
+that is already green pre-fix is not a valid task). Per the ADR, that gate
+is run by curation in ``$KEYS``; this grader trusts the curated row but
+re-asserts post-fix: exit 0 = pass (MERGE, score 100), non-zero = BLOCK
+(score 0). A partial-credit future variant would live here, not in the
+daemon.
+"""
+from __future__ import annotations
+
+import json
+import os
+import shlex
+import subprocess
+import sys
+from pathlib import Path
+
+
+REDS_REPLAY_TSV = "reds-replay.tsv"
+
+# Score bands mirror bench.sh's verdict_from_score: ≥90 MERGE, ≥50 FIXES, <50
+# BLOCK. A reds-replay check is binary (pass/fail), so we map pass→100/MERGE
+# and fail→0/BLOCK. The daemon records the verdict the grader emits.
+SCORE_PASS = 100
+SCORE_FAIL = 0
+
+
+def parse_args(argv: list[str]) -> tuple[Path, Path, str]:
+    args: dict[str, str] = {"worktree": "", "keys": "", "unit-id": ""}
+    it = iter(argv)
+    for a in it:
+        if a == "--worktree":
+            args["worktree"] = next(it)
+        elif a == "--keys":
+            args["keys"] = next(it)
+        elif a == "--unit-id":
+            args["unit-id"] = next(it)
+    if not args["worktree"] or not args["keys"]:
+        print(json.dumps({
+            "score": 0, "verdict": "BLOCK", "gate": "fail",
+            "reason": f"grader usage: --worktree and --keys required (got {args})",
+        }))
+        sys.exit(2)
+    return Path(args["worktree"]).resolve(), Path(args["keys"]).resolve(), args["unit-id"]
+
+
+def _verdict(score: int) -> str:
+    if score >= 90:
+        return "MERGE"
+    if score >= 50:
+        return "FIXES"
+    return "BLOCK"
+
+
+def emit(score: int, gate: str, reason: str) -> None:
+    out = {
+        "score": max(0, min(100, int(score))),
+        "verdict": _verdict(score),
+        "gate": gate,
+        "reason": reason,
+    }
+    print(json.dumps(out))
+
+
+def _load_reds_row(keys: Path, unit_id: str) -> dict[str, str]:
+    """Read ``$KEYS/reds-replay.tsv`` and return the row for ``unit_id``.
+
+    Columns (tab-separated): unit_id, check_cmd, expect_green_exit,
+    work_class, note
+    """
+    p = keys / REDS_REPLAY_TSV
+    if not p.exists():
+        return {}
+    for ln in p.read_text().splitlines():
+        if ln.startswith("#") or not ln.strip() or "\t" not in ln:
+            continue
+        cols = ln.split("\t")
+        if len(cols) < 2:
+            continue
+        if cols[0] == unit_id:
+            return {
+                "unit_id": cols[0],
+                "check_cmd": cols[1] if len(cols) > 1 else "",
+                "expect_green_exit": cols[2] if len(cols) > 2 else "0",
+                "work_class": cols[3] if len(cols) > 3 else "red",
+                "note": cols[4] if len(cols) > 4 else "",
+            }
+    return {}
+
+
+def _run_check(check_cmd: str, worktree: Path, expect_green: str) -> tuple[bool, int, str]:
+    """Substitute ``{worktree}`` in ``check_cmd`` and run it.
+
+    Returns (passed, exit_code, combined_output).
+    """
+    # Substitute the {worktree} placeholder (the ONLY interpolation; the
+    # check_cmd is read from a 0700 keys dir the agent cannot reach, so the
+    # agent never sees the literal command).
+    cmd = check_cmd.replace("{worktree}", str(worktree))
+    try:
+        proc = subprocess.run(
+            cmd, shell=True, cwd=str(worktree),
+            capture_output=True, text=True, timeout=120,
+        )
+    except subprocess.TimeoutExpired:
+        return False, -1, f"check_cmd timed out after 120s"
+    out = (proc.stdout or "") + (proc.stderr or "")
+    # expect_green is "0" means exit 0 == green (pass). Any other value means
+    # that exit code == green. Default: 0.
+    green_code = int(expect_green) if expect_green.strip() else 0
+    passed = (proc.returncode == green_code)
+    return passed, proc.returncode, out.strip()[:400]
+
+
+def main() -> int:
+    worktree, keys, unit_id = parse_args(sys.argv[1:])
+    row = _load_reds_row(keys, unit_id)
+    check_cmd = row.get("check_cmd", "")
+    if not check_cmd:
+        return emit(SCORE_FAIL, "fail",
+                    f"no check_cmd for unit '{unit_id}' in {keys}/{REDS_REPLAY_TSV}") or 0
+
+    expect_green = row.get("expect_green_exit", "0")
+    passed, rc, out = _run_check(check_cmd, worktree, expect_green)
+    if passed:
+        emit(SCORE_PASS, "pass",
+             f"check_cmd passed (exit {rc})" + (f": {out[:120]}" if out else ""))
+    else:
+        emit(SCORE_FAIL, "fail",
+             f"check_cmd FAILED (exit {rc})" + (f": {out[:120]}" if out else ""))
+    return 0
+
+
+if __name__ == "__main__":
+    sys.exit(main())
