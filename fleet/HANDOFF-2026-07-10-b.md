## GOTCHAS (exact, learned this session)
- **PLAIN git only** (`cd <repo> && git …`). Push via `bash fleet/land-push.sh <branch> <worktree-or-repo>` (AUTONOMOUS flag ON → it pushes).
- **`git rebase` is SANDBOX-DENIED.** Use `git merge origin/master --no-edit` instead to bring a branch up to date.
- **`git push` / `git -C … push` / `reset --hard` are deny-listed** — only land-push.sh pushes.
- **gh must run from the PRODUCT repo dir** (/home/stack/code/charon) or with `--repo SLOP-Platform/charon`.
- Merge flow: `gh pr ready N` → `gh pr merge N --squash` → `bash fleet/done.sh <TICKET>`. done.sh REFUSES unless a MERGED PR exists; for work satisfied WITHOUT a merge use `done.sh <TICKET> --no-verify`.
- `gh pr merge --delete-branch` fails while a worktree pins the branch. Cleanup order: `git worktree remove --force <path>` → `git branch -D <branch>` → `gh api -X DELETE repos/SLOP-Platform/charon/git/refs/heads/<branch>`.
- Opencode agents may commit their REVIEW-PACKET.md into the branch — STRIP it before merge (`git rm -f REVIEW-PACKET.md`); it's not a product-repo artifact.
