Build wave 1 of Charon's native work-engine (ADR-0010): the board + claim substrate. Read
docs/adr/0010-native-work-engine-substrate.md (D2 board + claim; the warm-ACP worker model;
the DTC corrections) and the ADR-0010 entry in docs/REVIEW-LOG.md FIRST.

KEY FRAMING: Charon's workers are **ACP agents** (warm-poolable), NOT `claude -p`. This
ticket builds COORDINATION STATE ONLY — no worker management, no process spawning, no
per-unit process restart.

GOAL: a durable, Charon-owned work backlog + atomic claim, as a THIN layer over existing
primitives (ledger.py's lock, parallel.py) — not a new subsystem.

BUILD:
1. src/charon/engine/__init__.py + src/charon/engine/board.py — a durable, file-backed
   backlog. A unit = {id, tier, owns (paths), depends_on, state}. One Charon-owned,
   diffable/auditable schema (reuse the unit shape from land.py's units loader where
   possible). CRUD + state transitions (ready/claimed/done/blocked). A unit is claimable
   only when its depends_on is done AND it shares no owned path with another in-wave ready
   unit (mechanize the coordinator.py collision rule).
2. src/charon/engine/claim.py — atomic claim as a THIN generalization of ledger.py's
   existing PID-liveness file lock (CONC-4) to N units. Add a monotonic claim EPOCH per
   unit as the double-execution fencing token (DTC Lens-4). Release on completion/crash; a
   stale claim is reclaimable only onto a FRESH worktree, never the in-flight one. Do NOT
   build heartbeat, remote-lease, or a second lock implementation — reuse/extend the ledger
   lock primitive.

Tests: tests/test_board.py, tests/test_claim.py — proven-red where possible: depends_on
gating, owned-path collision refusal, atomic claim under contention (never two holders),
epoch increments on reclaim, stale-claim reclaim targets a fresh worktree.

CONSTRAINTS: own ONLY src/charon/engine/__init__.py, engine/board.py, engine/claim.py,
tests/test_board.py, tests/test_claim.py. Import ledger/coordinator/land — do NOT edit them.
Stdlib-only core. Gate green on every commit (pytest, ruff check, mypy src/charon,
check_boundary.py src, check_version.py). No secrets. Conventional commits. If a non-trivial
design choice arises beyond ADR-0010, add a short docs/REVIEW-LOG.md note before code. Open
a DRAFT PR base=master; do NOT merge.
